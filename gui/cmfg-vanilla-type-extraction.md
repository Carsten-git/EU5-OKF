Glorp pattern **#5**: top-level vanilla widgets normally force copying every type/template in the file. Extract types into a sidecar; override file keeps constants + widget tree.

# Workflow

1. Use CMF’s `tools/extract_vanilla_types.py` (headers say `# Auto-generated by tools/extract_vanilla_types.py`).
2. Ship extracts under `in_game/gui/vanilla/`.
3. **Prefix uniquely** — Glorp uses `cmfg_*` so symbols do not collide with CMF’s own `cmf_*` extracts when both mods load.
4. Override file (e.g. `ingame_topbar.gui`) keeps `@topbar_height` etc. and the top-level widget; types come from the extract / your redefinition file.

# Glorp extended extract set (11)

Beyond CMF’s core list, Glorp also extracts: `map_markers`, `economy_lateralview`, `production_lateralview`, `battle_lateralview`, `recruit_location_lateralview`, plus topbar/location/outliner/government/foreign/single_unit.
