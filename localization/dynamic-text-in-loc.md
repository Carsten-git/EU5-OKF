# Variable interpolation

The pattern that works depends on **where** the loc string is rendered, because it decides which scopes exist.

## Static modifier tooltips (`STATIC_MODIFIER_NAME_*` / `STATIC_MODIFIER_DESC_*`)

The modifier tooltip is rendered in a **scope-less GUI context**:

* `ROOT.GetVariable(…)`, `ROOT.Custom(…)`, `GetPlayer.MakeScope.GetVariable(…)`, and `Country.MakeScope.GetVariable(…)` all **fail** for live values — names show `Error Error Root.Custom(…)`, desc renders blank ("/100"). See [KI-012, KI-015](/validation/known-issues.md).

**Working pattern — readout swap:** generate N static modifiers with the score baked into the name, swap monthly in script:

```yaml
 STATIC_MODIFIER_NAME_teu_nc_purpose_readout_62: "Purpose: 62/100 (Steadfast)"
 STATIC_MODIFIER_DESC_teu_nc_purpose_readout_62: "Whether Christendom still accepts our crusading mission…"
```

```txt
teu_nc_refresh_purpose_readout = {
    # remove teu_nc_purpose_readout_{old_slot}, add teu_nc_purpose_readout_{current_score}
}
```

Generated by `tools/generate_purpose_readout.py` in the Northern Crusade mod.

## Event text and other scoped contexts

Inside event titles/descs, `ROOT` is the event's country scope and `[ROOT.GetGovernment.GetRuler.GetName]`-style chains work normally.

| Token | Role |
|-------|------|
| `…GetVariable('name').GetValue\|0` | Integer formatting |
| `…\|+=2` | Signed, two decimals (e.g. +0.50) |
| `ROOT.Custom('key')` | [Customizable localization](/customizable-localization/) — scoped contexts only |
